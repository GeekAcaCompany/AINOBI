# AINOBI Courseware Codex Plugin

**Easiest install:** open ChatGPT Desktop Codex, drop this zip (or folder), and ask it to follow **[INSTALL.md](./INSTALL.md)** (“给 Codex 的安装步骤”).

MCP is **hosted**. Prefer: drop the zip into Codex and ask it to run **`install.sh`**. The download endpoint injects this environment’s `/mcp` URL into INSTALL.md / `.app.json`.

Also: issue an org automation key first, then register Developer Mode MCP + Bearer, then start a **new** chat.
